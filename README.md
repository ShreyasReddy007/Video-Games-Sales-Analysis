# Analysis of sales of video games

Video games are big business: the global gaming market is projected to be worth more than $320 billion by 2027 according to Mordor Intelligence. With so much money at stake, the major game publishers are hugely invested in creating the next big hit. But are games truly getting better?

* In this project, I explored the top 400 best-selling video games created between 1977 and 2020. CompareD a dataset on game sales with critic and user reviews to determine whether or not video games have improved as the gaming market has grown.


* The database contains two tables. We've limited each table to 400 rows for this project, but you can find the complete dataset with over 13,000 games on Kaggle.

The analysis supports the idea that the golden age of video games may have already passed. Although today's games are bigger, flashier, and backed by billion-dollar marketing campaigns, they aren't always better in terms of critical reception and user enjoyment. As the industry becomes more commercially driven, there's a growing gap between financial success and game quality.

Tools Used : Python (Pandas, Matplotlib, Seaborn), SQL for querying structured game data.
